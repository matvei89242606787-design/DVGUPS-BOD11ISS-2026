## 🥹 Как отправить домашку на проверку?
**1.** Проверьте чтобы в папке с домашкой была только домашка, ничего другого!

**2.** Открываем cmd в пути папки домашки.
🪟 Windows | 🍎 macOS | 🐧 Linux
---|---|---
В папке с домашкой нажимаем на путь к папке *(Он должен выделится)*, после чего вводим туда `cmd`, нажимаем Enter. | Открываем Терминал, пишем `cd `*(обязательно с пробелом в конце)*, переносим в окно Терминала папку с домашкой, нажимаем Enter.| ХЗ
*Гиф* | *Гиф* | *Гиф*

**3.** В командную строку пишем `git add .` и Нажимаем Enter. Это выберет все файлы в папке.

**4.** В командную строку пишем `git commit` и Нажимаем Enter. Это сохранит состояние выбранных ранее файлов.

**5.** В командную строку пишем `git push <Ваш репозиторий>` *(Пример: `git push IvanovII-BOD11ISS`)* и Нажимаем Enter. Это отправит все сохранённые файлы на GitHub.

> *Ваш репозиторий смотрим в таблице -> [StudentsList.md](https://github.com/matvei89242606787-design/DVGUPS-BOD11ISS-2026/blob/main/StudentsList.md)*
