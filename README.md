# 📗 Инструкция по скачиванию и отправке домашки
## 🤔 Как скачать файлы для домшних заданий?
**1.** Заходим в релизы (releases) ищем нужный нам релиз по теме либо дате.

*Гиф*

**2.** Поочерёдно нажимаем на название файлов в релзе, и выбираем папку для установки (ваша папка с notebook'ами).

*Гиф*

**3.** **_Всё готово!_** Нужные файлы у вас, преступайте к решению домашнего задания! 

> *P.S. Не забудьте сохранить Notebook перед его закрытием!*

## 🫣 Перед отправкой необходимо скачать Git
Официальная страница установки Git:

  ↳  https://git-scm.com/install/windows *(Не только Windows, есть установщик на macOS и Linux)*

Следуйте инструкциям на официальном сайте, после установки можете переходить к отправке домашки.

> *Если возникли проблемы с установкой Git обратитесь в __❓ Помощь__ по контактам выше...*

## 🥹 Как отправить домашку на проверку?
**1.** Проверьте чтобы в папке с домашкой была только домашка, ничего другого!

**2.** В папке с домашкой нажмите на путь к папке (Он должен выделится) после чего введите туда `cmd`.

*Гиф*

**3.1.** **ЭТО ДЕЙСТВИЕ ДЕЛАЕМ ОДИН РАЗ, КОГДА ОТПРАВЛЯЕМ ПЕРВУЮ ДОМАШКУ!!!**

  ↳  В командную строку пишем `git branch <Название ветки>` и Нажимаем Enter.

> Своё название ветки смотрим в таблице -> [StudentsList.md](https://github.com/matvei89242606787-design/DVGUPS-BOD11ISS-2026/blob/main/StudentsList.md)

**3.2** **ВОТ ЭТО ДЕЙСТВИЕ ДЕЛАЕМ КАЖДЫЙ РАЗ!!! ВКЛЮЧАЯ ПЕРВЫЙ**

  ↳  В командную строку пишем `git checkout <Название ветки>` и Нажимаем Enter.

> Своё название ветки смотрим в таблице -> [StudentsList.md](https://github.com/matvei89242606787-design/DVGUPS-BOD11ISS-2026/blob/main/StudentsList.md)

**4.** В командную строку впишите `git add .`. Это выберет все файлы в папке.

**5.** В командную строку впишите `git commit`. Это сохранит состояние выбранных ранее файлов.

**6.** В командную строку впишите `git push DVGUPS-BOD11ISS-2026 <Название ветки>`. Это отправит все сохранённые файлы на GitHub.

> Своё название ветки смотрим в таблице -> [StudentsList.md](https://github.com/matvei89242606787-design/DVGUPS-BOD11ISS-2026/blob/main/StudentsList.md)
